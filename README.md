# MAIM Group Comp

PvP group comp sheet for the MAIM guild (ESO, Xbox).

**Open it:** https://dreadazar.github.io/maim-group-comp/

One page, no accounts, no install. It is locked behind a MAIM code — the lead
posts the `MAIM-` block and everyone pastes it in to get the current roster.

Edits like a spreadsheet: click and type, `Enter` to move down, `Ctrl+V` to
paste a block from Excel, `Ctrl+Z` to undo.

Core is capped at 12; the bench is unlimited.

> The code keeps people without it out of the sheet. It is not security — this
> page is public and its source is readable. Do not put anything sensitive in it.
